# Onyx 运行时 UX 验收清单

本文档用于补足编译和单元测试无法覆盖的桌面运行时行为。涉及窗口装饰、窗口管理器、外部拖拽、系统打开方式、回收站、终端启动、DPI 和输入焦点的改动，必须在对应环境完成记录后再关闭任务。

## 验证环境记录

每次验收先记录以下信息：

- 日期：
- Onyx 提交：
- 操作系统：
- 桌面环境：
- 显示协议：X11 / Wayland / 其他
- 缩放比例：
- 输入法：
- 文件系统位置：
- 远程服务：SMB / WebDAV / S3 / 无

## 桌面窗口

- [ ] 主窗口启动后尺寸来自 `OnyxSettings.mainWindowWidth/mainWindowHeight`。
- [ ] 主窗口可手动调整大小，调整后重启仍恢复最近尺寸。
- [ ] 设置窗口默认尺寸来自 `settingsWindowWidth/settingsWindowHeight`，窗口边框可拖拽调整。
- [ ] 设置窗口调整后关闭，再次打开恢复最近尺寸。
- [ ] 图片查看器默认最大化打开，不进入独占全屏。
- [ ] 图片查看器可从最大化恢复、手动调整大小，并保持正常窗口装饰。
- [ ] 批量重命名窗口默认尺寸来自 `batchRenameWindowWidth/batchRenameWindowHeight`，可手动调整并缓存。

## 面板与拖拽

- [ ] `SINGLE`、`DUAL_VERTICAL`、`DUAL_HORIZONTAL` 三种布局切换后面板内容不丢失。
- [ ] 竖向双栏分割器显示横向调整语义，拖拽时左右面板比例连续变化。
- [ ] 横向双栏分割器显示纵向调整语义，拖拽时上下面板比例连续变化。
- [ ] 点击非活跃面板内文件、标签、地址栏或菜单时，同时完成激活面板和目标动作。
- [ ] 标签可在同面板内调整顺序，当前标签和后台标签状态不丢失。
- [ ] 标签可跨面板拖拽，目标面板接收后保留浏览历史、过滤、排序和视图模式。
- [ ] 本地文件可拖出到系统文件管理器或桌面。
- [ ] 外部文件可拖入当前目录。
- [ ] 压缩包条目拖出时生成临时导出文件，并在拖拽结束后按策略清理。

## 路径、协议与远程连接

- [ ] 地址栏输入 `smb://host` 后规范化为 `smb://host/`，不会退回原地址。
- [ ] 地址栏输入 `smb://host/share` 后可进入共享目录或显示认证提示。
- [ ] WebDAV 连接管理支持新建、编辑、测试、删除和打开连接。
- [ ] S3 连接管理支持新建、编辑、测试、删除和打开 bucket/prefix。
- [ ] 凭据保存策略选择“不保存”时，凭据只用于下一次请求。
- [ ] 凭据保存策略选择“当前会话”时，重启后不再可用。
- [ ] 凭据保存策略选择“系统钥匙串”但当前未实现时，显示明确错误，不写入明文文件。

## 外部平台能力

- [ ] `Open With` 在 Linux 桌面环境中列出 `.desktop` 应用并能打开目标文件。
- [ ] 回收站可用时删除进入回收站；不可用时提示降级或改走永久删除确认。
- [ ] 终端打开能在当前目录启动 shell。
- [ ] 文件监听失败时写入日志，并在当前面板显示自动刷新已降级提示。

## DPI、语言与长文本

- [ ] `uiScale` 为 75、100、150、200 时，标题栏、工具栏、状态栏和列表文本不重叠。
- [ ] 列表字号和行高运行时调整后，详情视图和画廊视图立即响应。
- [ ] 英文、简体中文、日语三种语言下设置窗口、凭据窗口、批量重命名窗口没有截断关键操作按钮。
- [ ] 长路径优先展示后部目录，面包屑和文本编辑模式都可读。
- [ ] 长文件名在详情视图中省略显示，表头与内容列保持对齐。
- [ ] 大目录加载期间 UI 不冻结，过滤和选择状态保持一致。

## 可访问性与键盘流

- [ ] 仅使用键盘可切换面板、打开地址栏、导航、刷新、复制、剪切、粘贴、删除。
- [ ] 对话框 `Esc` 关闭，确认按钮可通过键盘触发。
- [ ] 焦点从标题栏、侧边栏、面板、预览、状态栏之间移动时顺序可预测。
- [ ] 关键按钮和图标具备可读的 content description 或 tooltip。
